# Java 分析阶段 8 验收报告

正式组件 `pyxis-java-analysis` 交付 Java 17 分析基础能力，JDT Core 为 3.47.0，自有引擎为 1.0.0，通信协议为 2。应用服务消费现有配置根、路径、诊断、错误和关闭生命周期。

## 接口与运行契约

- Rust `AnalysisRequest` 和 `AnalysisResponse` 为公开请求入口，`protocol::AnalysisResult` 按操作交付具体字段；Java `Protocol` 维护对应请求与结果类型。
- 打开项目时登记源码根、完整 JAR 列表、语言和标准库；每份源码读取一次，在实例私有 workspace 建立资源与 WorkingCopy。
- 新增、替换、删除和移动先核验项目版本、文档版本及全部路径关系，再接纳文件集合；移动携带目标与完整源码。
- `configure` 接纳完整配置并刷新外部 JAR，保留内存文档；成功后推进项目版本，AST 和引用索引按该版本失效。
- 查询按 UTF-16 半开区间交付节点、绑定、类型、常量、参数、声明与引用；源码位置带文档版本，项目结果带项目身份和分析版本。
- 关闭完成协议 shutdown、JVM wait 和读取线程 join，再清理所属工作区；依赖和原始日志保留。
