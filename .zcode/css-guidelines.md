# CSS Guidelines

## 展示归属

- 样式必须按业务展示及强关联组件组织，页面必须通过已有组件和共同展示角色装配。
- 同一展示角色的基础布局必须由所属样式完整定义，状态和响应式变化必须归所属角色维护。
- 文档基础必须归基础样式，标题身份、字段、面板、反馈及第三方适配必须按各自组件职责维护。
- 组件规则必须随实际消费者维护，跨业务共同规则必须具有稳定且一致的展示语义。
- 样式重组必须同步模板绑定、动态绑定、渲染函数及实际行为选择器。
- 正式代码及 HTML 的样式导入必须使用所属 style.css，聚合依赖必须存在且保持无环；test 目录的样式必须由所属测试入口装配，静态样式检查必须排除 test 目录。
- 测试专用样式必须归所属 test 目录；正式样式聚合入口严禁承载测试专用样式。
- Vue 展示必须消费外部样式入口，稳定布局必须由 CSS 承载。
- 模块文档严禁包含 CSS 文件引用和样式规则。

## 布局责任

- 应用框架必须拥有标题栏、页签、导航及内容视口。
- 内容容器必须拥有外围留白、区块间隔及所属滚动。
- 标题身份区必须拥有标题、状态、路径、说明及操作换行。
- 分组必须拥有标题、内容留白及折叠，字段列表必须拥有逻辑字段间隔。
- 字段行必须拥有标签、控件及所属说明的位置，操作组必须拥有组内对齐和间隔。
- 对象、数组、对象数组与键值集合必须采用所属字段的左右两列，标签必须位于左列，完整集合内容及添加入口必须位于右列，折叠面板必须承担分组层级。
- 集合标签必须与内容顶部对齐，列间隔必须采用 12px，内部条目必须消费所属字段列，窄空间必须由集合右列提供横向滚动并保留控件可用宽度。
- 同一基础布局必须采用明确的 Flex、Grid 或普通文档流，模板必须表达实际展示角色。
- 严禁使用字符、Emoji、无语义占位或任意逐项偏移硬凑 UI；普通 UI 图标必须采用既有组件或 SVG，对齐与间距必须由所属布局承担。
- 可收缩内容必须采用适用的最小尺寸，视口剩余空间必须由所属内容区消费。
- 布局整理必须保持节点身份、焦点、输入原文、校验、选择和浮层锚点。
- 控件尺寸必须保持稳定，长内容必须通过自然换行、所属滚动或明确的布局变化适配。

## 参数与文字

- 共同角色必须统一固定尺度，组件局部几何尺寸只允许由所属组件维护。
- 需要协调变化的参数必须使用具有明确消费者的变量。
- 局部变量必须沿组件实际继承关系使用，清理变量必须核对 CSS、模板、运行时代码和主题入口。
- 普通文字必须消费设置派生的通用字体，路径、字段键、实体 ID 及代码必须消费所属等宽字体。
- 生产及对齐的主标题必须采用 18px、24px 行高和 650 字重。
- 普通内容必须采用已确认的 4px、8px 和 12px 关联间距、区块间距及容器留白。
- 标题身份区必须纵排，标题与状态必须同行，说明或路径必须间隔 2px。
- 生产及对齐的页头必须采用 52px 最小高度与 6px 上下留白，水平留白必须由所属容器承担。
- 生产及对齐的字段标签列必须采用 112px，窄窗口必须采用 100px，列间隔必须采用 12px。
- 名称与字段键、控件与所属说明必须间隔 2px，相邻逻辑字段必须间隔 8px。

## 主题与控件

- 主题颜色必须由设置领域生成，DOM effect 与 Naive UI Provider 必须消费同一主题模型。
- 主题映射必须同时提供明暗值，完整性及切换结果必须由类型和行为测试验证。
- 基础默认值必须支持启动及失败显示，运行时主题必须由正式主题入口提供。
- Naive UI 的公开颜色及控件参数必须优先由主题配置维护，业务排列必须由所属组件样式维护。
- 必要的第三方结构适配必须集中维护，并核对所属窗口及浮层的实际呈现。
- 输入、光标、IME、文本选择及提交行为必须由正式控件保留。
- 信号灯必须消费真实业务状态和已确认的颜色优先级，灯芯、内描边与外光必须由共同状态呈现维护。
- 普通 UI 必须采用 100ms 结构动效和 80ms 轻反馈，并消费减少动态效果偏好。

## 沉浸式与预览

- 沉浸式内部布局、字体、配色、游戏参数及运行规则必须按保护基线保留。
- 共同基础声明变化必须核对沉浸式内部的继承结果、计算样式和截图。
- 沉浸式外围标题及普通操作必须由所属普通组件维护。
- 两个预选必须保持各自的样式依赖和展示状态，当前版必须消费正式展示。
- 预览工具及样本专用浮层必须使用独立语义，正式展示必须由正式样式决定。

## 验证与维护

- CSS 检查必须依据实际解析结果和样式依赖图，诊断必须提供文件、行列、规则及原因。
- 固定尺寸及局部效果必须依据展示语义维护，变量来源必须沿实际依赖核对。
- 规则测试必须使用独立合法及违规夹具，真实仓库必须由正式检查入口验收。
- 布局尺寸、对齐、换行、滚动及浮层必须在浏览器验证，布局测量严禁写入行为测试。
- 验收必须覆盖全部场景、明暗主题、宽窄窗口及正式独有状态。
- 必须询问用户是否允许新增，否则格式化后的 CSS 总物理行数必须减少，源码、测试、脚本及规范必须共同计入授权新增预算。
