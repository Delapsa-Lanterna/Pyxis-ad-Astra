# CSS Guidelines

本文档规定当前样式归属、应用布局、沉浸式展示、主题与交互验收规则。组件的业务行为由所属模块维护。

## 视觉模型

- 主窗口采用高密度桌面数据工具布局，由标题栏、Mod 页签、左导航、工作区和详情区组织内容。
- 应用控件字体消费 `--font-sans`，当前值为 `Inter, Segoe UI, Microsoft YaHei, sans-serif`。字号与窗口尺寸分别控制。
- 沉浸式展示区消费内置原版中文位图字体，正文、分组标题和舰船标题各自具有正式字体角色；输入原文继续由现有控件呈现。
- 贴图按原始比例展示；像素资源使用 `image-rendering: pixelated`，图片预览使用 `object-fit: contain`。

## 文件 ownership

- `src/styles/index.css` 按 `base`、`titlebar`、`app-shell`、`workspace`、`overview`、`settings`、`config`、`file-history`、`schema-forms`、`tables`、`detail-pane`、`editors`、`file-editor`、`immersive-editors` 聚合样式。
- `src/main.ts` 消费唯一聚合入口；主窗口与子窗口共用该入口。
- `base.css` 拥有全视口基础、共享 token、Naive UI 覆盖及共享控件；业务布局归对应业务 CSS。
- 单组件局部规则使用 scoped CSS；被多个组件消费的规则归所属业务 CSS 或基础控件。
- 稳定布局写入 CSS。运行时色值、媒体结果、字形测量、预览比例与 canvas 像素尺寸由组件提供动态值。

## Token

- 应用共享间距消费 `--space-{1..4}`，对应4、8、12、16px；普通圆角消费 `--radius-{sm,md,lg}`。
- 共享颜色、滚动条与阴影消费各自正式 token。新增共享语义同时维护基础与暗色主题定义。
- 沉浸式 appearance 通过唯一主题 effect 注入固定游戏配色；面板、浮层和确认框消费同一配色。
- 沉浸式正文、设计类型与槽位标记的分段颜色由领域投影提供，canvas消费正式颜色角色。
- 普通控件边框为1px；沉浸式槽位标记的形状、3.5px线宽、层次与透明度属于原版绘制参数。
- 原版图标尺寸、3px行间隔、9px列间隔和10px分组留白归沉浸式布局，静态授权按文件、选择器、属性和值登记。

## 固定布局

- `html`、`body`、`#app` 填充视口，margin为0，外层overflow为hidden；元素采用border-box。
- 主框架为42px标题栏、38px页签与剩余工作区；左导航224px、工作区topbar62px、详情区280px。
- grid、flex与滚动容器维护最小尺寸和所属滚动边界；控件使用稳定尺寸或grid track。
- 沉浸式窗口保持固定字形尺寸并随容器重排；位图canvas按devicePixelRatio调整像素尺寸，字形和画布原点对齐物理像素，呈现尺寸消费实际像素尺寸，逻辑行高保持所属字体度量。
- 武器与战机默认内容宽400px、窗口430×700、最小340×480；舰船默认内容宽800px、窗口830×700、最小430×480。
- 战机预览消费80×80px区域与10px图文间隔，技术数据消费共用15px单行与3px行间隔；系统和武装分别消费所属关联行与换行布局。
- 舰船内容宽低于690px时后勤与战斗区纵向排列，低于430px时后勤列纵向排列；重排保留现有DOM、浮层和活动输入。
- 内容区拥有滚动，操作区保持可见；窗口放大扩展列宽，缩小触发文字换行与分组重排。

## 控件与内容

- Naive UI输入和选择共用30px最小高度、12px字号及紧凑覆盖；原文、焦点、IME和提交行为归原控件。
- 表格操作由当前选择、详情面板或专用窗口承载。按钮消费现有图标库与控件样式。
- 文本按容器宽度决定换行与截断；异步资源、错误和空状态保持所属布局空间。
- 位图文字保留DOM可访问原文；缺字显示方框及Unicode诊断，原文保留在所属编辑模型。
- 沉浸式显示设置与分支入口保留所属标题行，消费分组字库、共享细标题条与垂直居中的紧凑动作样式。

## 复用与验收

- 同类控件消费同一尺寸、边框、颜色、禁用态及反馈语义；弹窗与表单消费现有基座。
- 舰船、武器与战机共同消费位图文字、细分组标题、数值行、来源提示与浮层；领域投影维护各自信息分组、显示分支及原版参数。
- 画布、拖拽及槽位绘制保留所属领域职责；局部可复用展示规则登记实际消费者。
- 视觉修改先读取当前样式与同类组件，完成后执行自动检查及真实组件验收。
- 验收覆盖亮暗主设置、默认／放大／缩小窗口、滚动、hover、focus、disabled、输入与浮层。
- 原版面板使用同倍率截图逐项核对字体、颜色、行距、列宽、图标和预览；记录逻辑尺寸、DPI、实际资源与错误日志，用户确认后完成视觉项。
