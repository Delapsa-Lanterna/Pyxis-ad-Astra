# CSS Guidelines

本文档只规定 CSS 的组织、视觉尺度、主题、布局和交互写法。业务状态、保存协议和具体页面行为见 `.zcode/overview.md` 或所属模块文档。

## 视觉模型

- 主窗口采用紧凑的桌面工具布局；标题、正文、辅助说明和状态保持明确层次。
- 同类内容使用一致的字号、颜色和间距；强调色表达当前选择或动作状态。
- 应用文字使用 `--font-sans`；代码和文本编辑区使用所属等宽字体。
- 通用字体由设置派生同一字体族，主题 effect 更新 `--font-sans`，Naive provider 与默认文字测量消费相同值。
- 图片保持原始比例，预览使用等比适配；像素资源使用像素化渲染。

## 文件 ownership

全局样式位于 `src/styles/`，按展示职责分工。

- `app-shell.css`：主框架、导航、顶栏、内容区分配和应用级确认内容。
- `base.css`：视口基础、主题 token、滚动条、Naive UI 覆盖和共享控件。
- `config.css`：配置页、实体列表、编辑区、来源更新提示和 Mod 概览。
- `detail-pane.css`：记录详情、缩略图、字段摘要和详情动作。
- `editors.css`：规格与预览窗口、画布、检查器和编辑器控件。
- `file-editor.css`：文本窗口、编辑状态、行号和行列定位。
- `file-history.css`：文件历史摘要、双栈、条目和影响文件。
- `immersive-editors.css`：沉浸式面板、装配画幅、共享游戏控件和对话层。
- `index.css`：按依赖及覆盖顺序聚合全局样式。
- `overview.css`：工作区与游戏概览、Mod 卡片、加载诊断和新建 Mod 对话内容。
- `schema-forms.css`：字段分组、嵌套结构、数组、键值行和额外字段。
- `settings.css`：设置页、主题色选择、日志维护和顶栏搜索控件。
- `tables.css`：CSV 网格、单元格状态、列宽和单元格编辑浮层。
- `titlebar.css`：标题栏品牌、窗口操作和工作区菜单。
- `workspace.css`：Mod 页签、页签状态与操作、当前 Mod 导航。

`src/main.ts` 是样式加载入口，主窗口和子窗口共同加载 `index.css`。

`src/app/components/fonts/FontText.vue` 的 scoped CSS 负责通用文字表面、canvas 定位与可访问原文；业务样式通过所属角色入口安排文字位置。

## 主题与 token

- 共享颜色、间距、圆角和阴影必须使用正式 token；同一视觉语义必须使用同一 token。
- 新增主题 token 必须同时覆盖基础与暗色主题；运行时主题统一通过主题 effect 注入 CSS 变量。
- Naive UI 主题覆盖必须使用主题模型提供的具体颜色值；严禁从 DOM 反推主题。
- 局部自定义属性必须具有明确作用域；静态授权必须精确到文件、选择器、属性和值。
- 共享间距为 `--space-1` 至 `--space-9`，按 4 px 递增；常用间距为 4、8、12、16 px。普通圆角为 5、8、10 px，普通控件边框为 1 px。

## 布局与滚动

- 视口由 `html`、`body` 和 `#app` 填满，外层关闭滚动；元素统一使用 `border-box`。
- 主框架标题栏为 42 px，页签栏为 38 px，左导航为 224 px，工作区顶栏为 62 px，详情区为 280 px。
- Grid、Flex 和滚动容器必须声明适用的最小尺寸；可收缩内容使用 `min-width: 0`、`min-height: 0` 或 `minmax(0, 1fr)`。
- 滚动归内容所属区域；持续操作区保持可达，滚动条必须预留空间。
- 固定尺寸控件保持尺寸，内容通过换行、重排或滚动适配；浮层必须按当前锚点和视口重新定位。
- 布局调整必须保持节点身份、焦点、活动输入和浮层目标；尺寸测量必须使用当前容器。

## 控件与内容

- Naive UI 输入和选择采用紧凑样式，共享最小高度为 30 px，字号为 12 px。
- 同类控件必须共用尺寸、边框和交互状态；hover、focus、disabled 和选中态必须可辨认。
- 文本按用途选择换行或截断，截断内容必须提供完整查看入口。
- 输入样式必须保留光标、IME、文本选择和原文提交行为。
- 加载、错误和空状态在所属内容区呈现，并保持当前操作可达。

## 沉浸式编辑器特殊规则

- 沉浸式界面使用固定游戏暗色，面板、浮层和确认框共用外观。
- 布局与绘制以原版源码为依据；具体控件参数归实现维护，共享展示规则必须保持一致。
- 展示文字必须按实际字体独立消费原版加载结果；正文、标题、数值和筛选必须由沉浸式角色映射选择字体，关闭、不可用、加载中和失败时必须使用 `--font-sans` 及对应字号、字重和 1.2 行高。
- 位图文字必须保留 DOM 可访问原文，缺字必须有意显示一个英文问号并提供原字符 Unicode 定位，业务原文必须完整保留。
- 字号按逻辑尺度固定，画布像素尺寸按 DPR 调整；字形、描边和画布原点必须对齐物理像素。
- 窗口通过重排和滚动适配，必须保持输入与浮层连续性。
- 数据行间隔为 3 px，舰船列间隔为 9 px，常用图文和分组留白为 10 px。
- 武器与战机默认内容宽为 400 px，初始窗口为 430 × 700 px，最小为 340 × 480 px。
- 舰船默认内容宽为 800 px，初始窗口为 830 × 700 px，最小为 430 × 480 px。
- 装配初始窗口为 1280 × 720 px，最小为 960 × 640 px，使用连续网格与独立滚动区。
- meta 动作使用普通紧凑控件；编辑器内切角动作共用四角切除的无边框八边形。
- 矩形筛选、方形开关和游戏边框必须按语义复用共享组件。
- 对话层必须维护所属焦点和点击边界，关闭后必须恢复入口焦点。
- 输入原文由正式控件承载；字段浮层和临时调整必须接入现有输入协议，样式调整必须保留提交、取消与键盘操作。

## 复用与验收

- 同类展示优先复用已有组件与样式；抽取共享规则必须依据一致的视觉语义和实际消费者。
- 沉浸式内容布局必须由同一领域渲染器承载；编辑窗口与只读容器必须共用字体、行序、图文布局和媒体展示，容器必须拥有所属定位与滚动边界。
- 单组件样式使用 scoped CSS，共享样式归所属业务文件或基础控件。
- 稳定布局必须写入 CSS；运行时颜色、字形测量、媒体结果和画布尺寸由组件提供。
- 视觉验收必须覆盖明暗主题、窄窗口、滚动、交互状态、输入和浮层。
- 原版界面必须按同倍率截图核对字体、颜色、间距和绘制比例，记录逻辑尺寸、DPR 与实际资源；视觉项依据用户确认完成。
