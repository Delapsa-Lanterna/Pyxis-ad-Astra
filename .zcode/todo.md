## 批次验收

- 文档批次必须运行 `npm.cmd run lint:checks`、`npm.cmd run format:check` 与 `git diff --check`。
- 前端批次必须运行 `npm.cmd run lint`、`npm.cmd run typecheck`、受影响行为测试及 `lint:checks`；构建配置、依赖、资源装配或打包链路变化必须运行 `npm.cmd run build`。
- Rust 批次必须运行 `cargo fmt --manifest-path src-tauri/Cargo.toml --check`、`npm.cmd run lint:rust`，并通过 `npm.cmd run test:rust` 执行所属测试。
- 检查器规则变化必须运行 `npm.cmd run test:checks`；浏览器资源与文件寿命变化必须运行 `npm.cmd run test:resources`。
- 跨层批次必须组合执行实际受影响层的检查；发布验收必须运行前后端全量检查、Windows 路径矩阵与 `npm.cmd run tauri -- build --no-bundle`。
- 视觉批次必须核对明暗主题、宽窄窗口、滚动、悬停、焦点、禁用、文字布局与减少动态效果偏好；涉及桌面手势和窗口生命周期时必须验收实际 Tauri 窗口。
- 每批必须使用项目格式化工具完成全仓格式化，核对实际差异、暂存区、UTF-8 无 BOM、换行及用户修改，并运行 `git diff --check`。
- 验收必须记录完整命令、退出码、耗时、测试数量、失败位置、环境能力与未执行场景；测试工作区、报告与临时资源必须沿所属释放流程处理。
