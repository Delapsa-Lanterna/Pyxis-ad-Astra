# Text Guidelines

## 标点

- 可见文字只允许使用 ASCII 双引号、单引号和圆括号。
- 可见文字中的中文双引号、中文单引号和中文括号必须替换为对应 ASCII 符号。
- 可见文字中的 ASCII 双引号、单引号和圆括号必须像英文词语一样与相邻文字分隔。
- 引号或圆括号与文字相邻时，外侧必须保留一个 ASCII 空格；外侧是其它标点时可以直接相连。
- 代码语法、函数调用、表达式和插值语法不属于可见文字。

## 中英文间距

- 可见文字中的 CJK 字符与英文字符序列之间必须保留一个 ASCII 空格。
- 英文字母与数字之间的间距由业务文字语义决定。
- 缩写按英文字符序列处理。

## 检查范围

- 文档、界面文字、可见属性、诊断文字、schema 展示文字和生产代码中的用户文字必须遵守本规范。
- 静态检查必须扫描仓库内全部适用文字来源，并报告文件、行、列、规则和违规内容。
- 测试工具、检查器实现和代码语法只作为程序来源处理，不作为用户可见文字扫描。
