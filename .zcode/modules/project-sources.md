# 项目来源读取

## 定义

项目来源读取模块按实际来源根交付成套的内容、版本与可复用解析成果。

## 参考

### 拥有

- `src-tauri/src/services/project/sources/`：来源记录、发现、读取、Core 文档运行态、持久化与行为验证。

### 消费

- `src-tauri/src/io/csv_files.rs`：带版本的 CSV 字节读取与解析。
- `src-tauri/src/io/faction_index.rs`：势力索引引用的正式路径授权。
- `src-tauri/src/io/file_versions.rs`：文件与目录凭据的生成及核对。
- `src-tauri/src/io/json_files.rs`：带版本的 JSON 字节读取与解析。
- `src-tauri/src/io/paths.rs`：实际根、规范路径及父链授权。
- `src-tauri/src/services/project/model.rs`：来源投影消费的记录与表格类型。

### 装配

- `src-tauri/src/services/project/session.rs`：会话打开、来源接纳与持久化配置。

## 边界

- Core fields、graphics、文档目录和 Core CSV 按根与产品代次共享读取结果。
- Core 文档运行态按实际游戏根持有只读目录、共享引用及待持久化成果。
- IO 拥有字节与路径授权，parser 拥有格式语义，来源读取持有匹配的内容与版本。
- 写后失效从已接纳会话重用未变化实体记录与 CSV 摘要。
- 同一根和产品的并发读取只保留一个实际任务，后续请求等待其结果。
- 持久快照保存来源版本及可重建成果，业务索引与诊断归实际消费者构造。
- 来源记录按规范根和相对路径隔离，Mod 的编辑内容与稳定行身份归所属会话。
- 来源读取操作持有临时解析与凭据，原文字节在所属处理结束后释放。

## 链路

### 来源读取

1. 消费者交付实际来源根与所属来源定义。
2. 来源读取枚举授权文件，IO 交付字节及匹配版本。
3. 匹配的来源记录复用解析成果，变化的来源交给正式 parser。
4. 消费者从记录构造业务内容、诊断与摘要。
5. 所属接纳完成后集中持久化解析成果。

### Core 文档

1. 查询取得实际游戏根所属目录句柄。
2. 已加载目录返回共享只读成果。
3. 所属来源在锁外读取，结果接纳到捕获句柄。
4. 打开完成或失效释放时写入所属来源快照。

## 规范

- Core 单飞任务必须绑定所属缓存实例与产品，刷新替换实例后必须独立读取，旧任务只允许接纳到原实例。
- Core 文档加载必须在条目锁外执行，嵌套请求必须保留各目录成果；已释放句柄的迟到结果严禁写入重新登记的根。
- Core 目录命中必须交付共享只读引用，持久化必须在所属打开完成或显式失效释放入口执行。
- 内容和版本必须来自同一次字节读取，业务内容严禁搭配另一次磁盘读取的凭据。
- 原始字节必须按文件处理和释放，完整 CSV 行必须由所属表格运行态接纳。
- 持久化必须按规范来源根隔离并校验当前内容版本，匹配记录只允许复用所属解析成果。
- 来源发现与索引引用必须经正式路径边界授权，版本范围必须包含实际引用与任务目录。
- 缓存失效必须作用于所属根和来源，已有共享成果必须保持所属引用生命周期。
- 读取路径严禁持久化，来源快照必须在打开或刷新接纳及显式缓存释放入口集中写入。

## 陷阱

- 内容与版本分开读取会使编辑基线无法表达实际读入的内容。
- 持有目录条目锁执行嵌套读取会使同根请求无法完成。
- 缓存身份缺少实际来源根会使相同相对路径命中其他来源。
