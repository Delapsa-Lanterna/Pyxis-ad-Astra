# 统一右键菜单

## 定义

统一右键菜单模块提供窗口内的文本操作、界面刷新与标题栏动作分派。

## 参考

### 拥有

- `src/app/components/ContextMenu.vue`：菜单展示与操作回调消费。
- `src/app/composables/use-context-menu.ts`：窗口菜单状态、目标操作、事件生命周期与业务根登记。

### 消费

- `src/app/composables/use-window-close-state.ts`：窗口关闭期间的菜单收起及操作暂停状态。
- `src/shared/runtime/clipboard.runtime.ts`：官方文字剪贴板能力包装。

### 装配

- `src/app/TitleBar.vue`：标题栏菜单登记及导航与窗口动作交接。

## 边界

- 业务根拥有身份、刷新动作和未保存状态。
- 剪贴板 runtime 拥有系统文字读写交接。
- 快捷键分发器拥有菜单按键的优先路由。
- 窗口壳装配菜单并提供所属外观。
- 菜单拥有选区捕获、展示与动作分派。

## 链路

### 打开与执行

1. 业务根登记所属身份、刷新与标题栏动作。
2. 窗口右键事件交付目标与选区，已接管的画布保留平移。
3. 菜单按文本权限或业务根生成动作。
4. 文本动作消费剪贴板及原生输入命令，刷新交付所属业务回调。
5. 标题栏动作消费所属导航、最小化与关闭入口。

## 规范

- 标签业务动作必须由命中的业务根登记并捕获目标，菜单执行必须复核所属身份并复用统一关闭及键盘操作流程。
- 业务动作必须与刷新共同展示并位于刷新之前，刷新必须消费命中元素与最近业务根的明确刷新范围，禁用状态必须由该根判定。
- 关闭操作锁生效时必须收起菜单并暂停打开及动作分派，释放后必须恢复所属菜单能力。
- 剪切必须在剪贴板写入成功后删除原选区。
- 可编辑位置必须依次展示复制、粘贴、剪切、分隔线、清空和全选；只读文本必须提供复制和全选。
- 打开菜单必须保留原输入焦点与选区。
- 普通区域只允许提供刷新，普通文字选区必须在刷新前提供复制与分隔线；无刷新能力时必须禁用刷新。
- 标题栏必须依次提供设置、关于、分隔线、最小化和退出；标题栏菜单只允许在所属根命中时展示，清空与退出必须使用主题 danger 色。
- 根交接、释放、失焦和滚动必须关闭菜单；异步修改必须核对原控件、原文、选区和所属身份。
- 菜单必须采用 160px 最小宽度、12px 字号、30px 行高和主题细边框，悬停与键盘定位必须使用主题中性色，打开时必须保持未选中状态，菜单外部严禁绘制阴影。
- 菜单打开期间的 Escape 必须由菜单优先处理并结束本次菜单展示。
- 菜单数据读取与刷新必须消费所属业务根交付的动作。
- 退出必须消费当前窗口关闭守卫，设置与关于必须消费现有导航确认，最小化必须消费所属窗口动作。
