# 统一右键菜单

## 定义

统一右键菜单模块提供窗口内的文本操作、界面刷新与标题栏动作分派。

## 参考

### 拥有

- `src/app/components/ContextMenu.vue`：菜单展示与操作回调消费。
- `src/app/composables/use-context-menu.ts`：窗口菜单状态、目标操作、事件生命周期与业务根登记。

### 消费

- `src/shared/runtime/clipboard.runtime.ts`：官方文字剪贴板能力包装。
- `src/shared/types/feedback.types.ts`：宿主交付的错误反馈契约。

### 装配

- `src/app/TitleBar.vue`：标题栏菜单登记及导航与窗口动作交接。
- `src/app/WindowRuntime.vue`：本窗口唯一菜单实例、关闭操作锁与反馈输入。
- `src/app/composables/use-app-lifecycle-assembly.ts`：ContextMenuHost 的保存等待、优先按键与窗口实例绑定。

## 边界

- 业务根拥有身份、刷新动作和未保存状态。
- 剪贴板 runtime 拥有系统文字读写交接。
- 快捷键分发器拥有菜单按键的优先路由。
- 窗口运行装配交付 ContextMenuHost，绑定所属关闭状态、保存等待、优先按键登记与错误反馈。
- 菜单拥有捕获动作的关闭代次及异步接纳有效期。
- 菜单拥有选区捕获、展示与动作分派。

## 链路

### 打开与执行

1. WindowRuntime 建立本窗口关闭状态与反馈，应用装配创建宿主并挂载唯一菜单。
2. 业务根登记所属身份、刷新与标题栏动作。
3. 窗口右键事件交付目标与选区，菜单捕获关闭代次及登记身份，已接管的画布保留平移。
4. 菜单按文本权限或业务根生成动作，刷新等待宿主保存完成并复核捕获有效性。
5. 文本动作消费剪贴板及原生输入命令，刷新交付所属业务回调。
6. 标题栏动作消费所属导航、最小化与关闭入口。

## 规范

- 标签业务动作必须由命中的业务根登记并捕获目标，菜单执行复核所属身份并复用统一关闭及键盘操作流程。
- 菜单运行能力必须由 ContextMenuHost 明确交付，关闭状态、保存等待、优先按键与反馈绑定所属窗口实例。
- 关闭操作锁生效时必须同步结束已捕获动作的接纳权并收起菜单，恢复后新动作捕获当前关闭代次，旧动作保持失效。
- 剪切必须在剪贴板写入成功后删除原选区。
- 可编辑位置必须依次展示复制、粘贴、剪切、分隔线、清空和全选；只读文本提供复制和全选。
- 打开菜单必须保留原输入焦点与选区。
- 普通区域只允许提供刷新，普通文字选区必须在刷新前提供复制与分隔线；无刷新能力时禁用刷新。
- 标题栏必须依次提供设置、关于、分隔线、最小化和退出；标题栏菜单只允许在所属根命中时展示，清空与退出使用主题 danger 色。
- 根交接、释放、失焦和滚动必须关闭菜单；异步修改核对原控件、原文、选区和所属身份。
- 菜单打开期间的 Escape 必须由菜单优先处理并结束本次菜单展示。
