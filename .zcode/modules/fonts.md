# 字体

## 定义

字体模块提供按字体身份共享的字库与通用文字展示能力。

## 边界

- FontText 拥有默认文字 DOM、位图 canvas、DPI、缺字提示与监听。
- 业务领域拥有字体角色到实际字体的映射，页面拥有字号角色选择、强调色与布局。
- 后端字体读取拥有安全路径和 session 根补充，FNT 格式解析拥有页声明与字形度量的转换。
- 字体提供入口拥有图集解码与按图集身份的栅格缓存，窗口运行态按字体身份拥有状态与共享请求。
- 排版领域消费度量、原文片段与可用宽度，交付独立排布结果和墨迹范围。
- 消费者登记实际字体，窗口运行态拥有读取接纳与日志，文字和测量共同消费逐字体结果。
- 设置拥有通用字体与原版字体开关，沉浸式窗口以所属 session 装配和释放字体运行态。

## 链路

### 定义与图集提供

1. 沉浸式窗口按 session 提供字体运行态，消费者登记实际字体身份；候选屏外文字暂停测量和绘制，接近视口时由批处理调度。
2. 启用状态的首次登记通过所属读取票据请求原版字体。
3. 后端以设置根优先、session 根补充，读取 FNT 与声明的图集页。
4. 前端解析外部度量并解码该字体的全部图集页。
5. 票据接纳该字体就绪结果，或发布失败状态并记录一次诊断日志。

### 文字展示

1. FontText 接收字体身份、原文或颜色片段及展示选项。
2. 对应字体尚未就绪时，默认 DOM 按所选通用字体、正式字号、字重和颜色片段展示原文。
3. 对应字体就绪后，排版领域按字素和问号替代计算位置、换行及墨迹范围。
4. 组件按 DPR、所属图集页与描边范围建立 canvas，并保留可访问原文。
5. 测量消费者按相同字体状态重算筛选宽度与名称截断。
6. 容器变化重新测量，滚动和窗口变化更新物理像素对齐。

### 切换与释放

1. 开关或来源变化撤销读取票据并清空已接纳字体，当前文字采用默认字体。
2. 启用状态重新加载仍有消费者的实际字体，各项独立接纳。
3. 消费者卸载释放登记与文字监听，窗口释放撤销全部读取并清空定义和图集。

## 规范

- FNT 外部接入必须校验行高、基线、页声明、字形坐标及页引用、空格与问号字形；图集必须按页 ID 解码并校验声明尺寸。
- FontId 必须表达实际字体身份，业务角色必须由所属领域映射后交付。
- 分段颜色必须保持文本排布连续，测量、截断与绘制必须消费同一排布算法。
- 原版字体必须从授权安装根的 `starsector-core/graphics/fonts` 读取；图集必须消费 FNT 的实际 `page` 文件声明，文件路径必须经所属根边界授权。
- 失败必须按字体及本次尝试记录一次实际路径与原始诊断；重试只允许由重新开启、根变化及重新打开窗口触发。
- 字形栅格缓存必须区分图集、字形、颜色与描边，容量必须消费 settings 的启动预算，共享缓存只允许在所属 WebView 内维护。
- 字素与显式换行必须保持原文对应关系，缺字必须提供原字符与完整 Unicode 定位。
- 排版必须分别交付行布局与墨迹范围，画布必须容纳字形偏移和描边并对齐物理像素。
- 普通中文必须按字素换行，英文必须优先整词；超过可用宽度的连续内容必须按完整字素推进。
- 消费者释放必须解除自身登记；开关关闭、来源变化及窗口释放必须撤销所属读取，迟到值和错误必须由票据核对 session、根输入、字体和代次。
- 相同字体的并发消费者必须共享一次读取；每种字体必须独立就绪和失败，关闭、不可用、加载中和失败时必须采用 `--font-sans`。
- 缺失字素必须有意绘制为一个 ASCII `?`，步进与 kerning 必须消费问号字形；可访问原文与 Unicode 缺字诊断必须保留原字符。
- 通用展示必须保留可访问原文，业务输入必须由所属输入控件承载。
- 默认文字与测量必须消费设置派生的同一通用字体族；通用字体变化必须同步更新默认模式的宽度、截断与布局。

## 陷阱

- 把着色字形复用于另一张图集会让字体坐标与素材身份错配。
- 按业务角色建立解码缓存会让同一实际字体重复占用图集。
- 用墨迹高度代替行布局高度会让空行与段落节奏失真。
