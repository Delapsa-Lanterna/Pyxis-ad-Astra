# 字段编辑与输入交互

## 定义

字段编辑与输入交互模块按字段定义维护控件、原文提交、来源候选和所属交互生命周期。

## 边界

- 业务编辑器维护文档、草稿、目标及历史，字段编辑交付字段动作。
- 字段输入面持有原文、模式、焦点和所属等待，集合身份由所属文档维护。
- FieldEditorContext 绑定文档身份、局部覆盖、候选动作及来源订阅。
- 来源目录交付当前项目候选，字段编辑维护展示分组、值索引及目录外原文。
- 资源能力持有媒体读取和租约，字段编辑登记菜单及当前选项集合。
- JSON 组合能力维护继承、覆盖及稀疏修改规则，字段输入消费实际结果。

## 链路

### 字段显示与提交

1. 业务页面交付字段定义、FieldEditorContext 和所属 FieldInputs。
2. 字段与集合渲染器按有效模式展示控件并登记原文和稳定行身份。
3. 提交边界消费字段值规则，字段动作进入所属草稿和历史。

### 来源与释放

1. 捕获 session、source 或图片目录，按读取票据交接候选和选项媒体。
2. 保存及来源失效经原有有序内容处理等待所属重读，失败保留重试步骤。
3. 目标切换、输入取消和卸载结束所属订阅、票据、选区及媒体集合。

## 规范

- 字段问题定位必须按所属文档和完整路径展开已有分组，首次挂载与保留输入共同消费既有展开状态，异步定位仅接纳当前文档及输入寿命。
- 模式切换确认必须列出实际待提交字段；确认只允许取消所属控件原文，退出保留当前模式与输入。
- 身份字段的静态必填声明必须保留；局部覆盖状态由当前草稿的本地身份交付；字段标签与全部递归输入共同允许必填缺省，已提供内容校验类型、格式和取值约束。
- 组合字段必须分别消费本地值与引用值，缺省本地文本以暗色占位显示引用内容；来源名称必须在对应控件内右对齐显示。
- 缺失的颜色值必须保持未设置展示；颜色选择器的交互回退值不得显示为已保存字段值。
- 组合字符串输入清空必须提交显式空字符串；身份字段清空必须移除本地身份；恢复来源动作只在当前字段有本地覆盖且移除后仍有组合值时显示。
- 标签删除动作只移除一个选中值；任何来源继承的对象字段均不得显示删除动作；对象字段、数组条目与分组删除动作必须采用结构删除图标并标明对象。
- Plain 数字、布尔与 Smart 数字必须登记原文；非法输入保留正式字段类型并阻止提交，可选具名字段清空删除键，必填字段清空定位为错误。
- Smart 数值按钮必须按字段步长执行加减，普通点击、Shift、Ctrl 与 Shift+Ctrl 分别采用 1、5、0.5 与 50 倍；整数步长四舍五入且至少为 1，结果截取到字段声明的 min/max 边界，并经所属原文提交入口交付。
- Smart 来源引用必须支持搜索、选择与逐字符手填列表外值，菜单与已选标签共用同一 `SelectOption`；待提交原文登记到所属输入集合。
- 游戏数字必须统一解释完整输入，整数与浮点字段分别准备目标格式，未修改位点复用所属文档的源写法。
- `partial` 对象必须允许省略和删除本地覆盖字段，完整性交给合并后的保存校验。
- `plain` editMode 只允许文本或 JSON 文本；`smart` editMode 才允许增强控件；多行文本必须由 `text` 类型声明。
- `variants` 必须按实际 JSON 类型选择所属表单，新增条目采用所选格式初值，既有结构保留。
- 分组消费 EditorCollapse 与 EditorCollapseItem；可增删对象组及列表对象项初始收起，新增组展开，固定组消费所属默认值，首次展开后的隐藏保留所属输入；`presentation: groups` 将一级对象分别成组并将其余值归入额外字段。
- 原版 tags、hints 与 UI 标签必须按 Starsector 版本及完整表列 source 查询；数字规则通过独立模板选项交付默认输入值与有效上限，选择填入标签自定义输入，并经所属 FieldInputs 提交；具体数字说明来自匹配的来源规则。
- 图片候选必须按声明目录及子目录查询当前 Mod 和原版，同路径采用 Mod 优先，任务图片按当前任务目录交付相对路径；查询只允许交付路径元数据。
- 图片候选来源更新必须消费所属目录能力的失效判定并只重读实际受影响范围。
- 图片输入必须显式声明 `imageDirectories` 候选目录数组，缺失或空数组交付空候选；目录只允许约束候选展示，手动路径沿用所属路径基准与授权。
- 字典名称使用原文输入，引用候选归字段值；键值字段保持所属值类型并消费其默认值，同层改名拦截重名与保留名称，点号、中文和下划线作为原始键处理。
- 来源槽位键集合必须在明确选择候选后新增，打开或取消选择保留原值；候选排除本集合已有键，选中值只显示原始 ID，所属文档、船体或集合切换关闭选择。
- 字符串字段只允许提交字符串；Plain 整数必须按完整十进制和安全整数范围解析，浮点按完整有限十进制解析，非法文本逐字符保留。
- 对象条目必须按名称索引匹配身份，列表按内容摘要及重复项原顺序匹配并保留等长位置接续；集合复用未变化行的定义、内容及校验，结构动作共同交接身份与内容，并保留现存节点、焦点和展开态。
- 已选值必须按逐字符身份消费目录值索引，首尾空白完整保留；目录和索引共同失效，数字模板独立于具体值索引。
- 文字原文经 FieldInputs 提交；单行 Enter、多行 Ctrl+Enter 或离开输入各交付一次正式更新，Escape 取消所属输入。
- 未登记字段及原版发现字段必须服从所属 schema 的 allowExtraFields 声明；Smart 模式只允许 true 展示扩展区且空内容保留入口，缺失、`null`、空字符串和空集合分别保留。
- 沉浸式复合字段必须由 `FieldInputs` 终结器在全部原文有效后交付一个字段集合；结构化数组消费共享 JSON 输入解析，必填分支阻止空值提交。
- 缺省布尔值必须按所属字段默认值显示，原版字符串布尔值按实际含义显示；挂载严禁写入默认值，未经编辑的必填空输入参与保存校验。
- 装配模块浮层必须以正式 slotId 定位模块引用，并保留对象或有序条目数组形态；字段提交交给所属联合草稿。
- 路径字段消费 pathBase；Mod 路径相对 Mod 根，Mission icon 相对任务目录，候选目录和选择器服从同一基准。
- 颜色文本与面板调整必须登记为同一字段输入；保存提交有效颜色，取消恢复已提交颜色。
- 额外字段必须由业务内容与已声明键集合决定；对象默认关闭扩展，顶层、嵌套对象与列表元素独立声明，关闭对象的额外数据原样保留并跳过编辑与校验。
