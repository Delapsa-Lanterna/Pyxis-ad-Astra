# Spec 弹体编辑器

## 定义

弹体编辑器模块提供弹体及导弹规格的结构化编辑与保存交接。

## 参考

### 拥有

- `src/app/components/spec-editor/projectile/`：弹体画布、检查器与行为测试。
- `src/app/composables/spec-editor/projectile/`：弹体文档、分支字段、视口与绘制装配。
- `src/app/renderers/spec-editor/projectile/`：弹体外观、碰撞与引擎静态场景。
- `src/domain/spec-editor/projectile/`：弹体分支、引擎槽位与静态几何规则。
- `src/services/spec-projectile-editor.service.ts`：弹体编辑数据与草稿图像的独立查询。

### 消费

- `src-tauri/src/domain/entity_definitions.rs`：八种实体的目录、后缀、ID 字段及规格、表格关联登记。
- `src-tauri/src/services/project/definitions/projectiles.rs`：Mod 弹体及 Core 回退的正式读取。
- `src-tauri/src/services/project/resources/entity_references.rs`：舰船、武器、弹体、系统及配置实体的授权资源字段映射。
- `src/shared/ui/FieldHints.vue`：检查器说明的共同展示。
- `src/windows/spec-editor.window.ts`：四类规格的身份、尺寸与结构化窗口请求。

## 边界

- ProjectSession 拥有弹体实体、Mod 优先读取与 Core 回退，查询交付正式目标及版本。
- 弹体 ViewModel 拥有文档装配、视口、静态绘制、折叠状态、字段和贴图引用选择动作。
- 弹体场景消费共享本体绘制并持有检查标记，草稿图像运行态交付授权引用，共享图像运行态持有解码及成品释放。
- 弹体领域拥有创建、分支转换、归一化和完整引擎默认值，编号分配消费共享纯原语。
- 武器引用与选项目录归武器模块，开火预览拥有完整弹体读取及模拟。
- 统一提交管线拥有历史、项目正式内容与失效，消费窗口分别接纳所属依赖。
- 规格窗口会话拥有 dirty、保存、外部基线、身份交接和关闭。

## 链路

### 打开与编辑

1. 武器动作提交输入并捕获弹体 ID，交付所属 session 与 Mod 根。
2. managed 窗口入口创建或复用 projectile 规格窗口。
3. 弹体查询交付单份规格、实际目标、版本和创建状态。
4. 窗口会话接纳规格，弹体 ViewModel 装配 projectile 或 missile 表单。
5. 字段与引擎动作经编辑文档发布所属工作值。

### 静态检查

1. 窗口宿主按当前草稿和基线读取授权弹体图像，交付读取状态与诊断。
2. 弹体领域投影当前尺寸、中心、碰撞范围和引擎，图像运行态交付当前贴图。
3. 属性、资源、主题、尺寸及导航触发静态场景重绘。
4. 初次挂载与重置视图按当前几何适配，后续接纳保留视口。

### 保存与更新

1. 保存动作提交活动输入并捕获独立规格快照。
2. 窗口会话完成身份准备，正式事务返回实际内容和完整 receipt。
3. 统一管线接纳历史、项目正式内容与身份，发布所属实体和目录失效。
4. 弹体窗口交接基线，武器目录和开火预览分别重新读取。

### 外部接纳与释放

1. 外部读取和保存事件进入所属规格窗口会话。
2. dirty 外部内容暂存，明确载入交接活动输入和规格基线。
3. 弹体文档消费 EditContext 接纳当前规格，折叠状态归当前组件实例。
4. 窗口释放会话、输入、读取与异步资源选择接纳权。

## 规范

- missile 的 engineSpec 必须完整表达 turnAcc、turnRate、acc 与 dec。
- 保存必须消费当前实际目标；同 ID 保存保留实际路径，Core 来源在当前 Mod 的默认路径创建覆盖。
- 导弹引擎必须将 loc 与角度转换后消费共享普通满推力静态成品及正式样式资源，尾焰在弹体上层，控制点在编辑覆盖层。
- 引擎新增必须提供唯一 ID、loc、角度、宽高及完整 CUSTOM styleSpec；引擎槽位只允许在 missile 分支编辑。
- 弹体和导弹创建必须消费共享模板的独立克隆；分支转换保留业务字段并补齐缺失必读字段。
- 弹体引用必须由正式字段按 ID 交接，行为中的分裂弹体、分裂后弹体及四项音效按游戏实际分派条件显示并保留隐藏数据，类型切换先提交所属活动输入。
- 检查器必须区分必填缺失与有效默认值，图片尺寸同步消费当前已接纳资源；组内动作进入文档历史，固定对象默认关闭扩展，behaviorSpec 通过 FieldSchema 显式开放。
- 视口必须归窗口运行态；适应视图消费视口状态，实际平移或缩放清除适应状态，单纯右键按下保留状态；缩放、平移与重置只允许修改展示状态，规格修改经字段动作交接。
